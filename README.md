# FlavorApp

Seamlessly integrates [FlavorTown](https://flavortown.hackclub.com) in a desktop app.

It shows the website in a desktop app! And adds features!

## ✨ Features:

- **Settings**: Change how FlavorApp behaves for it's features
- **Auto Updater**: Automatically updates the app to the latest version
- **Can-Buy Notifications**: Notifies you when you reach one of your cookie shop goals

> [!IMPORTANT]
> This app is not _signed_ which means your antivirus will likely not like this.
>
> - To bypass default protection on windows, you have to click "More Info" and "Run Anyway"
> - On mac, you have to run this command in your terminal to un-mark it as flagged: `xattr -d com.apple.quarantine /Applications/FlavorApp.app` (or the real app path if it's not in your Applications)
